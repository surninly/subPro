# sumin-todolist-pro

**데이노트(daynote)** — React와 JavaScript로 만든 챗봇 TODO 웹 앱입니다.

## 실행

Node.js 22.12 이상 또는 24 LTS 환경을 권장합니다.

```bash
npm install
npm run dev
```

터미널에 표시되는 주소를 브라우저에서 엽니다. 기본 주소는 `http://localhost:5173`입니다.

## 주요 기능

- 직접 입력하거나 챗봇에게 말해서 일정 추가
- 체크박스로 완료 / 미완료 전환
- 전체 / 미완료 / 완료 필터, 제목 검색, 일정 삭제
- 완료율과 상태별 일정 개수 표시
- 브라우저 로컬 저장소에 일정 자동 저장: 새로고침해도 유지
- 데스크톱, 태블릿, 모바일에 대응하는 반응형 화면
- 키보드 입력과 스크린 리더를 고려한 폼과 상태 안내

처음 실행할 때 예시 일정 4개가 표시됩니다. 필요에 따라 삭제하고 사용할 수 있습니다.

## 챗봇 사용법

| 입력 예시 | 동작 |
| --- | --- |
| `전체 일정 알려줘` | 현재 전체 일정 표시 |
| `완료한 일정 알려줘` | 완료한 일정만 표시 |
| `미완료 일정 알려줘` | 아직 하지 않은 일정만 표시 |
| `남은 일정 보여줘` | 미완료 일정 표시 |
| `일정 보고서 제출 추가해줘` | ‘보고서 제출’ 일정 추가 |
| `일정 보고서 제출 삭제해줘` | 해당 일정 삭제 |
| `일정 보고서 제출 완료해줘` | 해당 일정을 완료로 변경 |
| `도움말` | 사용할 수 있는 명령 안내 |

- `일정 @@@ 추가해줘`, `일정 @@@ 삭제 해줘`에서 `@@@` 자리에 실제 일정 이름을 넣습니다.
- `추가 해줘`, `추가해주세요`, `삭제 해줘`, `지워줘` 등의 표현을 지원합니다.
- 같은 이름의 일정을 중복 추가하지 않습니다.
- 삭제 시 정확한 이름을 우선합니다. 일부 단어만 일치하는 일정이 하나라면 해당 일정을 찾고, 여러 개라면 후보를 안내합니다.
- 일정 이름은 200자까지 입력할 수 있습니다.

## 저장 방식과 범위

챗봇은 **한국어 명령어를 해석하는 규칙 기반 방식**입니다. 유료 AI API, API 키, 별도 서버 없이 작동합니다. 일반 주제에 관한 자유로운 AI 대화는 제공하지 않습니다.

일정은 현재 브라우저의 `localStorage`에 저장됩니다. 다른 기기나 브라우저와 동기화되지 않으며, 사이트 데이터를 삭제하면 일정도 삭제됩니다. 저장소를 사용할 수 없는 경우 화면에 안내합니다. 대화 내용은 현재 탭이 열려 있는 동안만 유지됩니다.

## 검증

```bash
npm test
npm run lint
npm run build
```

명령 조회 / 추가 / 삭제 / 완료, 중복·빈 제목 처리, 이름이 비슷한 일정 보호, 저장 데이터 복구를 자동 테스트합니다.

배포용 정적 파일은 `dist`에 생성됩니다.

```bash
npm run preview
```

## 파일 구조

```text
src/
  App.jsx        # TODO 화면, 챗봇 화면, React 상태 관리
  todo.js        # 일정 처리, 한국어 명령 해석, 저장 데이터 읽기
  index.css      # 반응형 스타일
  main.jsx       # React 시작점
public/
  daynote.svg    # 앱 아이콘
tests/
  todo.test.js   # 기능 테스트
```

React 19 / Vite 8 / JavaScript를 사용합니다. TypeScript 소스는 사용하지 않습니다.
